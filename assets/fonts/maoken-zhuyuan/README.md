# 猫啃珠圆体网页字体

本目录包含作品页主标题与副标题使用的“猫啃珠圆体”网页字形分包。

- 原字体作者：猫啃网、Little White Dog、频凡
- 原字体版本：1.000（2023-02-22）
- 官方来源：https://www.maoken.com/freefonts/17948.html
- 网页字形分包来源：https://www.npmjs.com/package/cn-fontsource-maoken-zhuyuan-ti-regular
- 授权协议：SIL Open Font License 1.1，详见 `OFL.txt`

为了控制 GitHub Pages 的加载体积，项目只保存了“作品集锦”及其中文副标题实际使用字符所在的 WOFF2 分包，未保存完整字体文件。
